Process Equation Guide

Isochoric

V = constant

W = 0

ΔU = nCᵥΔT

Q = ΔU

Isobaric

P = constant

W = P(V₂ − V₁)

ΔU = nCᵥΔT

Q = ΔH = nCₚΔT

Isothermal

T = constant

PV = constant

ΔU = ΔH = 0

W = nRT ln(V₂/V₁)

Q = W

Reversible Adiabatic

Q = 0

PVγ = constant

TVγ−1 = constant

γ = Cₚ/Cᵥ

W = −ΔU
